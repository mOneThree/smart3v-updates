Smart 3V board setup

First-time install for a new board over USB. After this, updates arrive through Home Assistant.

This browser cannot talk to USB serial devices. Open this page in Chrome or Edge on a computer, over https or from localhost.

Connect and install

Plug the board in with a data USB cable and close any serial monitor. If it does not connect, unplug it, hold BOOT, plug it in, then release.

This erases the board completely. A board that is already paired loses its pairing and gets a new pairing code.
